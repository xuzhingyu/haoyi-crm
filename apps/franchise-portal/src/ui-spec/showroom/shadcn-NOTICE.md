# shadcn/ui reference

The isolated showroom references the Card, Chart, Field and Input Group compositions from shadcn/ui. The interactive analytics examples adapt the official area/bar chart composition to the existing Haoyi tokens and local fixtures, using Recharts 3.10.1. No shadcn preset, Tailwind reset or production business flow has been installed.

The following showroom refinement also references Button variants and data slots, Card header/content/footer composition, Field/FieldSet/InputGroup structure, Tabs, Navigation Menu, Dialog, Sheet and Dropdown Menu. These are adapted to existing native selection controls and the application's Presence/useOverlay lifecycle. No additional dependency was added for this refinement.
