# 上线闸门与个人信息保护影响评估清单

上线负责人必须逐项记录“通过/不通过、证据链接、负责人、日期”。未通过项目不得以功能开关规避。

## 数据与用途

- 每个来源有管理单位、条款/robots、允许页面和字段、访问频率及停用条件。
- 已发布记录 100% 具有来源 URL、抓取时间、证据、解析器版本和文档哈希。
- 300 条人工样本字段匹配率不低于 98%，目标门店分类准确率不低于 90%，自动合并无误合并。
- 不把法定代表人或经营负责人推断为实际老板；不采集私人手机号。
- 个人字段双开关默认关闭；专项评估通过后才由 HQ 管理员开启。
- 加盟协议、隐私告知、权利申请和投诉处理流程已经法务批准并可实际执行。

## 营销边界

- 不提供自动拨号、群发短信、群发微信、邮件群发或加盟商导出。
- 明确退订立即进入全平台 DNC；解除只能由 HQ 管理员调用 `POST /api/v1/admin/listings/{id}/dnc-lift`，选择“对方主动联系”或“取得新同意”并填写证据引用，操作写入审计后仅回到待补充库存。
- “暂时不需要”冷却 90 天，冷却期不出现在可领取池。
- 页面含加盟商、用户和时间水印；明文详情访问写审计。

## 安全与隔离

- Keycloak 关闭公开注册，总部邀请，一家加盟商一个组织，最多 3 个成员。
- OIDC 使用 Authorization Code + PKCE；生产禁用开发身份头。
- 组织 ID 只取令牌；跨组织读取、修改和 ID 猜测返回 404/403。
- PostgreSQL RLS 已在真实 PostgreSQL 验证，不以 SQLite 测试代替。
- 负责人和自由文本加密密钥来自密钥管理系统，不写入仓库或镜像。
- HTTPS、备份加密、最小权限、防火墙、补丁和漏洞扫描已验收。

## 运行与恢复

- 100 并发领取同一线索恰好一个 201，其余 409。
- 300 个账号、50 RPS 压测，读取和领取 P95 小于 500ms。
- Twenty 中断不影响领取，恢复后 Outbox 无丢失和重复。
- 数据库与对象存储已完成一次隔离环境恢复演练，并记录 RTO/RPO。
- 原始快照 30 天清理；证据、审计和评估 3 年；加盟终止数据 180 天删除/匿名化策略已落地。

本清单是产品与工程控制，不替代中国执业律师对具体来源、营销方式和个人信息处理活动的意见。
